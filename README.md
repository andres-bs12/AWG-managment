# ArtWithGab (AWG)

Seguimiento de ventas de ornamentos de Navidad personalizados: pedidos, agenda de pintura, pagos (Stripe / efectivo) e inventario.

## Contexto

Proyecto operativo para la temporada de mercados navideños 2026 (Viena). Stack previsto:

- Backend: Java + Spring Boot
- Frontend: React + TypeScript
- Base de datos: PostgreSQL
- Pagos online: Stripe

El desarrollo de la aplicación empieza tras el Sprint 1 (concepto y mockups en Figma). Este repositorio arranca con la documentación base; el esqueleto de código se añadirá cuando toque la base técnica.

## Cómo se trabaja

1. Sprints semanales (~15 h) gestionados en Jira.
2. Diseño (Figma) va por delante del desarrollo.
3. Demo revisable con Gaby al final de cada sprint.
4. No incluir secretos (tokens de Jira, Stripe, etc.) en el repositorio.

## Estado actual

Repositorio inicial. Sin aplicación compilable todavía. Próximo foco: identidad, flujos y prototipo navegable (Sprint 1).
